NestList -- music library licences
==================================
Every file in this directory must be listed here with its source and licence
BEFORE it ships. A track nobody can account for is a track we cannot defend.

All tracks are levelled to about -9.8 LUFS to match soft_piano.mp3. This is not
cosmetic: video_renderer.py applies ONE fixed volume to whichever track it picks,
so a track mastered quieter simply plays too quietly in the finished video. One
candidate measured -28.8 LUFS -- 19 dB below the reference -- and would have been
effectively silent. Normalise every new track to match before adding it here.

  purpose, so it stays eligible for every property type and both tiers keep at
  least two options.
